# GERELTUYA

Өөртөө зориулсан цагаа захиалаарай.

Монголын гоо сайхны салон, студиудад зориулсан цаг захиалга болон бизнес удирдлагын платформ. Нэг кодын сангаас нийтийн сайт, үйлчлүүлэгчийн апп, бизнес эзэмшигчийн апп, мэргэжилтний апп, админ самбар ажиллана.

## Технологи

- Next.js 15 (App Router), React 19, TypeScript (strict)
- Tailwind CSS v4, Framer Motion
- Prisma 6 + PostgreSQL (Supabase эсвэл Neon)
- Серверийн үйлдэл (Server Actions), JWT cookie нэвтрэлт (`jose`, `bcryptjs`)
- Зураг хадгалалт: Vercel Blob (заавал биш, холбоосоор зураг оруулах боломжтой)

## Хэсгүүд

| Хэсэг | Зам | Эрх |
| --- | --- | --- |
| Нийтийн сайт | `/`, `/search`, `/b/[slug]`, `/s/[id]`, `/book/[slug]` | Нээлттэй |
| Үйлчлүүлэгчийн апп | `/app` | CUSTOMER |
| Бизнес эзэмшигчийн апп | `/owner` | BUSINESS_OWNER (зөвхөн өөрийн бизнес) |
| Мэргэжилтний апп | `/staff` | STAFF |
| Админ | `/admin` | ADMIN |

Үндсэн боломжууд: хайлт ба шүүлтүүр, 5 алхамт захиалга ("Хэн ч байсан болно" сонголттой), цаг өөрчлөх ба цуцлах, хадгалах, үнэлгээ, мэдэгдэл, календарь (өдөр, 7 хоног, сар, чирж шилжүүлэх, цаг хаах), үйлчилгээ ба мэргэжилтний удирдлага, үйлчлүүлэгчийн бүртгэл (CRM), орлогын статистик, CSV тайлан, 7 алхамт онбординг, FREE/PRO/BUSINESS багц, админы баталгаажуулалт ба хяналт.

## Орон нутагт ажиллуулах

Шаардлага: Node.js 20+, PostgreSQL 14+.

```bash
npm install
cp .env.example .env        # утгуудыг бөглөнө
npx prisma migrate deploy   # хүснэгтүүдийг үүсгэнэ
npx prisma db seed          # демо өгөгдөл оруулна
npm run dev                 # http://localhost:3000
```

Шалгалтууд:

```bash
npm run typecheck
npm run lint
npm run build
```

## Орчны хувьсагч

`.env.example` файлд бүгд байгаа. Нууц утгыг хэзээ ч git-д оруулахгүй.

| Нэр | Тайлбар |
| --- | --- |
| `DATABASE_URL` | PostgreSQL холболт (Supabase бол pooler, порт 6543, `?pgbouncer=true`) |
| `DIRECT_URL` | Шилжилтэд ашиглах шууд холболт (порт 5432) |
| `AUTH_SECRET` | Дор хаяж 32 тэмдэгт. `openssl rand -base64 32` |
| `NEXT_PUBLIC_SITE_URL` | Сайтын бүтэн хаяг (sitemap, OG зурагт) |
| `CRON_SECRET` | `/api/cron/maintenance` дуудлагын нууц түлхүүр |
| `BLOB_READ_WRITE_TOKEN` | Заавал биш. Зураг оруулахад |
| `SMS_PROVIDER`, `EMAIL_PROVIDER`, `PAYMENT_PROVIDER` | Одоогоор `demo`. Бодит үйлчилгээ холбогдоогүй |

## Өгөгдлийн сан ба seed

Схем: `prisma/schema.prisma`. Шилжилт: `prisma/migrations`. Seed нь тогтмол (deterministic) бөгөөд бүх огноо өнөөдрөөс хамаарна, тиймээс байршуулалтын үед дахин ажиллуулна.

Seed нь 9 идэвхтэй бизнес (NOIR STUDIO, LUNA NAIL, NORTH BARBER, MUSE BEAUTY, SORA LASH, ATELIER HAIR, NUDE STUDIO гэх мэт), 2 баталгаажуулалт хүлээж буй бизнес, мэргэжилтнүүд, үйлчилгээ, ажлын цаг, 120 хоногийн түүх болон ирэх 21 хоногийн захиалга, үнэлгээ үүсгэнэ.

## Байршуулалтын архитектур

```
Хэрэглэгч -> Vercel (Next.js, серверийн үйлдэл, API) -> Supabase PostgreSQL
                         |
                         +-> Vercel Cron (өдөр бүр 03:00 UTC) -> /api/cron/maintenance
                         +-> Vercel Blob (зураг, заавал биш)
```

1. Репозиторыг Vercel-д холбоно.
2. Орчны хувьсагчдыг тохируулна (`DATABASE_URL`, `DIRECT_URL`, `AUTH_SECRET`, `NEXT_PUBLIC_SITE_URL`, `CRON_SECRET`).
3. `npx prisma migrate deploy` ба `npx prisma db seed`-ийг нэг удаа production өгөгдлийн сан руу ажиллуулна.
4. `npm run build` нь `prisma generate`-ийг автоматаар ажиллуулна.

## Хэрэгжилтийн тэмдэглэл

- Цагийн бүс: Asia/Ulaanbaatar (UTC+8), бүх цагийг UTC-ээр хадгална.
- Давхар захиалгаас хамгаалах: гүйлгээ дотор мэргэжилтэн тус бүрээр `pg_advisory_xact_lock`.
- Орлого: зөвхөн "Дууссан" захиалгаас тооцно. Дууссан цагаас 2 цагийн дараа захиалга автоматаар "Дууссан" болно.
- Мэдэгдэл: апп доторх мэдэгдэл ажиллана. SMS, и-мэйл, push нь интерфэйс бэлэн (`src/lib/notifications`), бодит үйлчилгээ холбогдоогүй.
- Төлбөр: багц солих нь туршилтын горимд ажиллана, жинхэнэ төлбөр хийгдэхгүй (`src/lib/payments`).

## Мэдэгдэж буй хязгаарлалт

- Демо зургууд Unsplash холбоосоос ачаалагдана. Ачаалагдахгүй бол нэрийн эхний үсэгтэй орлуулагч зураг харагдана. Бизнес эзэмшигч өөрийн зургийг профайлаас оруулна.
- Газрын зураг, координатаар "хамгийн ойр" эрэмбэлэлт нь дүүргийн төвийн ойролцоо координат дээр суурилсан.
- Календарьд чирж шилжүүлэх нь компьютер дээр ажиллана. Утсан дээр захиалгыг дарж "Цаг өөрчлөх" сонгоно.
